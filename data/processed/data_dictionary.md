# Data Dictionary

## Project
AI Educational RAG Assistant

## Dataset
Cleaned Educational Resources

## Purpose
This dataset contains structured educational information that will be used as the knowledge base for the AI Educational RAG Assistant.

## Fields

| Field | Description |
|---|---|
| title | Title of the educational resource |
| topic | Main subject or topic covered |
| content | Main educational information |
| source | Origin of the educational resource |
| category | Category of the educational material |
| keywords | Important terms related to the content |

## Data Processing

The initial educational resources are cleaned and structured before being used in the Retrieval-Augmented Generation (RAG) pipeline.

## Future Use

The processed dataset will later be converted into suitable chunks and representations for retrieval and used to provide context to the AI assistant.
